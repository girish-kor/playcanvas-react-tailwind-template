# Security policy

## Supported versions

This is a template repository (single `main` branch, no version releases).
Only the latest commit on `main` is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, use GitHub's private reporting:
[Security → Report a vulnerability](https://github.com/girish-kor/playcanvas-react-tailwind-template/security/advisories/new)
on this repository.

You should expect an initial response within a few days. If the report is
accepted, a fix will be prepared and a GitHub Security Advisory published
once it's available.
